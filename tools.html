Reference catalog

Tool guidance for modern delivery teams

A practical breakdown of where each tool fits, what it is strongest at, and how it contributes to a reliable CI/CD and QA automation system.

CI/CD and Delivery

These tools coordinate the repeatable steps that turn commits into tested, deployable artifacts.

CI/CD

GitHub Actions

Best for repository-native automation where pull requests, checks, releases, and packages live in GitHub.

  • Fast onboarding for GitHub-hosted projects.
  • Matrix builds for versions and platforms.
  • Strong marketplace ecosystem.
Official documentation
CI/CD

Jenkins

Best for highly customized automation, self-hosted runners, legacy integrations, and compliance-heavy environments.

  • Deep plugin ecosystem.
  • Declarative and scripted pipelines.
  • Strong fit for private infrastructure.
Official documentation
Platform

GitLab CI/CD

Best for teams that want source control, CI, security scanning, registry, and deployment workflows in one platform.

  • Pipeline-as-code in the repository.
  • Integrated DevSecOps features.
  • Useful for end-to-end platform governance.
Official documentation

Runtime and Infrastructure

These tools make environments repeatable, scalable, and easier to recover when production changes.

Runtime

Docker

Packages applications with their dependencies so development, CI, and production behave consistently.

  • Portable application images.
  • Predictable CI environments.
  • Foundation for container deployment.
Official documentation
Orchestration

Kubernetes

Schedules, scales, and heals containerized applications across clustered infrastructure.

  • Rolling updates and rollbacks.
  • Service discovery and scaling.
  • Production-grade orchestration.
Official documentation
IaC

Terraform

Defines cloud and platform infrastructure as reviewable configuration with repeatable state management.

  • Declarative provisioning.
  • Multi-cloud workflows.
  • Change review before apply.
Official documentation

QA Automation

These tools protect user journeys, browser compatibility, API contracts, and performance budgets.

PWE2E

Playwright

Fast end-to-end testing across Chromium, Firefox, and WebKit with auto-waiting and trace diagnostics.

  • Modern browser automation.
  • Strong debugging artifacts.
  • Excellent fit for web apps.
Official documentation
Browser

Selenium

Longstanding WebDriver automation standard with broad language, browser, and grid support.

  • Large ecosystem.
  • Enterprise compatibility.
  • Useful for legacy coverage.
Official documentation
Frontend

Cypress

Developer-focused web testing with fast local feedback for UI, component, and end-to-end workflows.

  • Great developer experience.
  • Time-travel style debugging.
  • Strong frontend feedback loop.
Official documentation
API

Postman

API design, testing, collection sharing, monitoring, and headless CI execution through Newman.

  • Shared API collections.
  • Mocking and documentation.
  • Regression checks in CI.
Official documentation
BSDevices

BrowserStack

Cloud-based real device and browser coverage for exploratory and automated compatibility testing.

  • Real device coverage.
  • Parallel browser matrixes.
  • Useful for release confidence.
Official documentation
Load

Apache JMeter

Performance and load testing for web applications, APIs, databases, and protocol-level systems.

  • Throughput benchmarking.
  • Stress and soak testing.
  • Release performance gates.
Official documentation

Observability

These tools close the loop after deployment so teams can detect regressions, debug incidents, and improve planning.

Metrics

Prometheus

Pull-based time-series metrics, dimensional labels, and PromQL queries for service and infrastructure health.

  • Open metrics collection.
  • Alerting workflows.
  • Strong Kubernetes fit.
Official documentation
Dashboards

Grafana

Shared operational dashboards and alerting across metrics, logs, traces, and production health signals.

  • Multi-source dashboards.
  • Operational views for teams.
  • Incident investigation support.
Official documentation
