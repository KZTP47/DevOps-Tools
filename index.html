Recommended Stacks

Three concrete combinations for teams at different maturity levels.

Lean Web Team

  • GitHub Actions for CI
  • Docker for consistent environments
  • Playwright plus Postman for E2E and API checks

Platform Team

  • Terraform for repeatable infrastructure
  • Kubernetes for app orchestration
  • Prometheus and Grafana for feedback

Enterprise QA

  • Selenium or Cypress where legacy/browser fit matters
  • BrowserStack-style device coverage
  • JMeter-style performance testing before release
